# 📈 Sales Prediction using Machine Learning

## 📌 Project Overview
This project was developed as part of my **CodeAlpha Machine Learning Internship**. It predicts product sales based on advertising expenditure across different media channels using a Machine Learning model called Linear Regression.

## 🎯 Objectives
- Analyze advertising data.
- Understand the relationship between advertising and sales.
- Perform data preprocessing and exploratory data analysis.
- Build a Linear Regression model.
- Predict sales based on advertising budgets.
- Evaluate model performance.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Project Features
- Dataset loading and exploration
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Train-test splitting
- Linear Regression model training
- Sales prediction
- R² score evaluation
- Actual vs Predicted Sales visualization
- Error Distribution visualization
- Feature Importance visualization
- Correlation Heatmap
- Pairplot visualization

## 📁 Dataset Information
The project uses the Advertising dataset.

**Important Features:**
- TV Advertising
- Radio Advertising
- Newspaper Advertising
- Sales (Target Variable)

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/santosh1503-aj/Sales-Prediction.git
```

2. Navigate to the project folder:

```bash
cd Sales-Prediction
```

3. Install the required libraries:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
```

4. Start Jupyter Notebook:

```bash
jupyter notebook
```

5. Open `Advertising.ipynb` and run all cells.

Developed a Linear Regression model to predict sales using TV, Radio, and Newspaper advertising expenditure. Evaluated model performance using the R² score and visualized the predictions.
